# Sonic Browser Integration Release Notes

Sonic Browser Integration connects your web browser to SonicDE, so media controls, downloads and browser tabs work together with your desktop.

## 6.8.0 (2026-10-20)

- Behind the scenes: version update and refreshed dependency versions.

## 6.7.5 (2026-09-12)

- Behind the scenes: version update.

## 6.7.4 (2026-08-03)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.7.3 (2026-07-14)

- Browser integration no longer carries code for Wayland, a display system SonicDE doesn't use, keeping it focused on the SonicDE desktop.
- Behind the scenes: restored the code formatting settings and added support for developers' code-navigation tools.
